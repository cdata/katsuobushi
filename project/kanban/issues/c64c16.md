## What happened

`resolveCargoConfig` in `lib/rust/default.nix` appends `("config.toml",
"config")` per directory and lets `config.toml` win the merge. Real cargo does
the **opposite** — measured: `warning: both .../config and .../config.toml
exist. Using .../config`.

Found by peer review of 333168, which constructed the resulting false green: a
valid legacy `config` with no source replacement beside a crane `config.toml`
gives checker `rc 0 "aligned"` while cargo rebuilds all 91 units.

Low frequency (a deprecated dual-config setup), but it falsifies the resolver's
stated purpose of reproducing cargo's own resolution — which is the only reason
its verdicts can be trusted.

## Acceptance criteria

- [ ] Legacy `.cargo/config` takes precedence over `.cargo/config.toml`, per cargo
- [ ] The dual-config false green from the review no longer reproduces
- [ ] A test covering both orderings, derived from cargo's documented behaviour
