## What to build

The `design` skill: the authoring ritual that takes rough notes to an accepted
PDD. A new skill at `plugins/katsuobushi/skills/design/SKILL.md` (auto-discovered;
loads as `katsuobushi:design`).

The ritual, in order (PDD002 Body):

1. Load the `grilling` skill.
2. Interview the author one question at a time; settle every open decision.
3. Load `simple-english`; pick one word per concept before drafting.
4. Draft to the six template sections (`project/design/README.md`).
5. Match accepted PDDs for structure and depth, not voice.
6. Write in Simplified Technical English; short sentences.
7. Read the draft as a person with no context; close gaps with examples,
   pseudocode, diagrams, links.
8. Write the file to `project/design/` at the next free `PDDNNN` (never `PDD000`).

- **Voice priority:** STE wins over the older PDDs' longer sentences.
- **Numbering:** read `project/design/` for the highest `PDDNNN`, add one.
- **Fallbacks:** grilling absent -> one-question-at-a-time inline rule (each with
  a recommendation, no draft until agreement); simple-english absent -> inline
  digest (short sentences, active voice, one word per concept, no filler, no
  semicolon).

Match the house voice/length of the existing skills (project / sandbox /
project-orchestration). Reference, do not restate, the PDD template and PDD001.
