## What to build

A command that moves a branch **into** an instance's mirror — the opposite
direction of `sandbox fetch`.

`sandbox fetch` moves a branch from an instance to the orchestrator. There is no
command for the other direction, so the orchestrator has been running a raw
`git push` at another instance's storage path by hand. That works, and nobody
can test it or fix it, because it is not a verb.

Two callers need it:

- Giving a **reviewer** the branch under review. A guest sees exactly one host
  directory (`lib/sandbox/default.nix` lines 221-224), so no instance can read
  another instance's mirror. The orchestrator is the only path between two
  parties.
- Refreshing a **resumed** instance's base to the current tip (filed
  separately).

Shape it like `fetch`: a `SandboxCommand` variant in
`rust/katsuobushi-controller/src/main.rs`, dispatched in
`rust/katsuobushi-controller/src/sandbox/mod.rs`, and a module beside
`fetch.rs`. Reuse the existing seams — `resolve_instance`, `load_spec` /
`resolve_roots`, and `host::run_ok` — so it is testable the same way `fetch.rs`
is.

The destination is `<stateGlob>/<inst>/sync.git`. Settle during the work:

- The name the branch takes in the target mirror. It must not collide with the
  target instance's own `sandbox/<inst>` branch, which the guest checks out and
  commits on.
- Whether the source is a local ref, another instance, or either.
- Whether the push is forced, and what guards a force needs. `fetch` refuses
  when the update would orphan local descendants; the analogous risk here is
  overwriting a branch the target guest is working on.

## Acceptance criteria

- [ ] One documented command puts a branch in another instance's mirror, with
      no raw `git push` at a storage path
- [ ] The command lives beside the other sandbox verbs, takes an instance name
      or index like they do, and honours `--json`
- [ ] Unit tests cover it through the host seam, in the style of `fetch.rs`
- [ ] The branch it delivers does not collide with the target instance's own
      working branch
- [ ] The sandbox skill documents the verb next to `sandbox fetch`, including
      what it does not do
