## What to build

F5 of `design/warm-artifacts.md`, independent of F1-F4 and lower priority.
Everything else in that design shares artifacts within one host; a declared
substituter extends it across machines and CI:

```nix
rust = katsuobushi.lib.rust {
  cache = { url = "https://…"; publicKey = "…"; };
};
```

The motivating case is a second machine (e.g. a macOS workflow) with no binary
cache, where a from-scratch build is on the order of an hour.

## Acceptance criteria

- [ ] `cache = { url; publicKey; }` accepted and wired into the builds
- [ ] Absent `cache` behaves exactly as today
- [ ] Documented in the `lib/rust` README, including how a consumer populates it
