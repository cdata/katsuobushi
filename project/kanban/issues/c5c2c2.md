## What to build

The work state answers what the stall notice was guessing at. The knob's right
value depended on a project's cold-build time, which is the class of guess this
design exists to remove. This repo runs the library default of
`progressStallSecs ? 300` (`lib/sandbox/default.nix:124`) and passes no override
from `flake.nix`, so the host printed a stall notice about five minutes into
every cold build.

Remove `progressStallSecs` from the library arguments and the host spec, and
remove the stall notice from the host watchdog
(`rust/katsuobushi-controller/src/sandbox/prompt.rs`).

The independent check does not disappear with the knob. It moves into the
heartbeat contract: a heartbeat that always beats reaches its own declared
timeout and becomes late.

## Acceptance criteria

- [ ] A cold build produces no stall notice.
- [ ] `progressStallSecs` appears in neither the library arguments nor the host
      spec.
- [ ] The stall-notice path is gone from the host watchdog, along with any test
      that only covered it.


## Added scope (from the `a91d4c` review)

**Host-found defect referred to the reviewer — the new migration note misstates
the work-state vocabulary it is introducing.** `MIGRATING.md:18-20` says:

> `Active (Late)` means heartbeats have stopped and the guest may be stuck;
> `Idle` means the agent stopped without reporting.

Both contradict the design. PDD003 `:266-268`: *"`late` is not a fourth state.
It is a flag on `active`. A heartbeat past its timeout is by definition **still
beating**, and one that stops is **not late but absent**."* And `:270`:
*"`idle` is the floor. It means nothing runs. It carries **no accusation**."*
The design's own table reads `active (late)` as "Work runs past its own declared
bound" and `idle` as "Nothing runs".

So the note tells an upgrading consumer that late means stopped (it means still
running, past its bound) and that idle means the agent failed to report (it
means nothing is running, which is equally true of a healthy finished turn).
This is the first thing a consumer reads about the new vocabulary.
