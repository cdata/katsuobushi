## What to build

The work state answers what the stall notice was guessing at. The knob's right
value depended on a project's cold-build time, which is the class of guess this
design exists to remove. This repo runs the library default of
`progressStallSecs ? 300` (`lib/sandbox/default.nix:124`) and passes no override
from `flake.nix`, so the host printed a stall notice about five minutes into
every cold build.

Remove `progressStallSecs` from the library arguments and the host spec, and
remove the stall notice from the host watchdog
(`rust/katsuobushi-controller/src/sandbox/prompt.rs`).

The independent check does not disappear with the knob. It moves into the
heartbeat contract: a heartbeat that always beats reaches its own declared
timeout and becomes late.

## Acceptance criteria

- [ ] A cold build produces no stall notice.
- [ ] `progressStallSecs` appears in neither the library arguments nor the host
      spec.
- [ ] The stall-notice path is gone from the host watchdog, along with any test
      that only covered it.
