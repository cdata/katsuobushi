## What to build

The guest combines every heartbeat into one **work state**. The rule is a
logical OR over the set, read in one precedence order:

```
  finished   the agent ran a terminal report for this turn
     >
  active     one or more heartbeats beat
             (late)  a beating heartbeat is past its own timeout
     >
  idle       nothing beats
```

- `finished` outranks every observation. The agent's own terminal report is
  authoritative about the turn. An agent that reports `done` while a build still
  runs reads as `finished`; the leftover process is not allowed to hide
  completed work. The risk is guarded already — the `project-orchestration`
  skill tells an orchestrator to trust the branch and not the VM.
- `late` is **not** a fourth state. It is a flag on `active`. A heartbeat past
  its timeout is by definition still beating; one that stops is not late but
  absent.
- `idle` is the floor. It means nothing runs, and it carries no accusation.
- `finished` belongs to one turn. A new prompt clears it, and the state returns
  to whatever the heartbeats say.
- The grace window after a stop (`stopGraceMs = 1500`) is unchanged. It still
  absorbs a terminal report that arrives just after the stop hook, so a clean
  finish is never misread as a silence.

**`ended-unreported` leaves the vocabulary.** The state it named is now `idle`,
and the cases it confused are now separate.

## Acceptance criteria

- [ ] A terminal report during a beating heartbeat yields `finished`.
- [ ] A heartbeat past its timeout beside a healthy one yields `active` with the
      late flag raised.
- [ ] No beat yields `idle`.
- [ ] A new prompt clears `finished`, and the state returns to what the
      heartbeats say.
- [ ] A terminal report that arrives inside the 1500 ms grace window after a
      stop still yields `finished`.
- [ ] `ended-unreported` appears nowhere in the guest, the protocol, or the host.
- [ ] The precedence rule is decided in a pure core and unit-tested without
      timers, BDD-named — e.g. `it_prefers_finished_over_a_beating_heartbeat`,
      `it_flags_late_without_leaving_active`, `it_falls_back_to_idle`.
