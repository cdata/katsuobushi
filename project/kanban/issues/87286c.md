## What to build

The nudge stops firing on a clock. It fires on the **transition into `idle`**
while a turn has ended with no terminal report.

That transition is the moment the build finishes. The agent is fetched back
exactly when it can do something useful, and the work no longer completes into
an empty room. The budget is spent only on real silence.

```
  turn ends, build runs         build ends
        │                            │
        ▼                            ▼
  ┌───────────┐               ┌───────────┐
  │  active   │──────────────▶│   idle    │──▶ nudge ──▶ agent verifies
  │ Compiling │  heartbeat    │           │             and reports done
  └───────────┘  stops        └───────────┘
     no nudge spent               nudge #1
```

- The budget widens to **five nudges, one minute apart**. Roughly five minutes
  replaces roughly 91.5 seconds, and every second of it now buys tolerance for a
  slow or briefly stuck harness rather than being burned inside a build.
- When the budget runs out the guest stops. The VM stays `idle` and carries the
  spent count, so an operator sees that the agent was asked and did not answer.
- The budget belongs to the turn. It does **not** refill when work resumes. An
  agent that starts a second build after a nudge returns to `active`, and the
  next silence spends the next nudge from the same budget. A heartbeat that
  flaps therefore cannot nudge an agent forever.
- A **late heartbeat provokes nothing.** It can occur alongside a live turn, and
  a nudge is a poor instrument for "go investigate". Interrupting a working
  agent to tell it a background process overran turns a slow build into a lost
  one. `late` is loud in the status, and a person decides.
- `nudge_text` no longer instructs a yielded agent to wait on a background
  command.

## Acceptance criteria

- [ ] A turn that ends while a heartbeat beats spends no nudge. The nudge count
      stays at zero for the length of the build.
- [ ] The first nudge arrives when the last heartbeat stops, within a minute of
      the transition into `idle`.
- [ ] Five nudges go out one minute apart, then the guest stops. No sixth nudge
      is injected, and the state holds `idle` with the spent count.
- [ ] A heartbeat that stops and restarts does not refill the budget.
- [ ] A heartbeat past its timeout injects no nudge while the flag is up.
- [ ] `nudge_text` carries no instruction to wait on a background command.
- [ ] The schedule is decided in the pure core and unit-tested without timers,
      BDD-named — e.g. `it_spends_no_nudge_while_a_heartbeat_beats`,
      `it_nudges_on_the_transition_to_idle`, `it_stops_nudging_at_the_budget`,
      `it_does_not_refill_the_budget_when_work_resumes`.

## Review notes

### Round 1 — `review-87286c-91edfa56` — VERDICT: accept

Gates observed by the reviewer: all 558 workspace tests pass, lint clean.

Every hazard raised in the review directive was checked and cleared:

- **`nudge_pending` cannot leak across turns.** A new `Turn` struct resets it
  (`server.rs:351`).
- **It cannot fire spuriously.** A four-way guard (`server.rs:554-559`) requires
  `ended && !terminal_reported && nudge_pending && nudges < max_nudges`.
- **A heartbeat restart cannot refill the budget.** `WorkStateActive`
  (`server.rs:572`) only clears `is_work_idle`; the monotonic `nudges` counter
  on `Turn` is untouched. Pinned by
  `it_does_not_refill_the_budget_when_work_resumes`.
- **Rust and Nix defaults agree** — `MAX_NUDGES_DEFAULT = 5` /
  `NUDGE_INTERVAL_MS_DEFAULT = 60000` in `protocol/lib.rs`, `maxNudges = 5` /
  `nudgeIntervalMs = 60000` at `default.nix:265-266`, bound to env vars at
  `:1147-1148`. No shipped-vs-documented mismatch.
- **A late heartbeat suppresses nudges identically to a healthy one** —
  `Active { is_late: true }` still sends `WorkStateActive`
  (coordinator `:1174-1176`).
- **`nudge_text`** no longer mentions background commands, pinned by
  `it_nudge_text_does_not_mention_background_commands`.
- **The three updated existing tests kept their assertions** — only the
  `WorkStateIdle` prerequisite was added, and the new BDD tests cover the
  active-defer path those tests no longer exercise. No loss of strength.

**`nudge_pending` can remain set indefinitely if `WorkStateIdle` never fires** —
a heartbeat that beats forever. The reviewer judged this design intent rather
than a defect: the operator sees `active`, and recovery happens on the idle
transition. Worth knowing, since it is the one way this mechanism can decline to
recover a turn.
