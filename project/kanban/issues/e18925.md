## What to build

Add a `--label=<value>` option to `project status` so an epic can be read as a
filtered view of the board. An epic is just a shared label; the view is the
board narrowed to the cards that carry it. No new field, no reserved prefix, no
migration.

Rules (from the design):

- **Exact match.** `--label=PDD007` selects a card whose `labels` list contains
  exactly the token `PDD007`. A label is a whole token, not a substring.
- **Composition is AND.** The filter narrows the same listing `--lane` and
  `--available` produce. `--label=PDD007 --lane=needs-review` and
  `--label=PDD007 --available` both work. `--label` must **not** conflict with
  `--lane`/`--available` in clap.
- **Repetition is AND.** `--label=PDD007 --label=security` selects a card that
  carries both.
- **Output is the normal flat listing.** The filter hides non-matching cards; it
  does not group the board or change card order.
- **Opt-in.** With no `--label`, the listing is unchanged.

### Seam (verified against the tree)

- `CardView.labels` already exists and is populated (`query.rs:35`, `:189`), so
  no projection change is needed.
- Add a `Vec<String>` `--label` field to `StatusArgs` (`main.rs:123-137`).
  It must coexist with `--lane`/`--available` (unlike `--available`, which
  `conflicts_with_all`).
- Destructure it in `mod.rs:72-78` and thread it into `query::show`
  (`mod.rs:105-113`), parallel to `available`.
- Thread the param through `query::show` (`query.rs:40`) into `list_all`
  (`query.rs:70`) and add a `views.retain(...)` in the filter block at
  `query.rs:100-105`: keep a view whose `labels` contains every requested label.

## Acceptance criteria

- [ ] `project status --label=<v>` narrows the board to exactly the cards that
      carry `<v>`, in board order.
- [ ] Match is exact-token, not substring.
- [ ] `--label` composes (AND) with `--lane` and `--available`.
- [ ] Repeated `--label` is AND across labels.
- [ ] No `--label` leaves the listing unchanged.
- [ ] Unit tests, BDD-named: `it_selects_only_cards_that_carry_the_label`,
      `it_matches_a_label_exactly_not_as_a_substring`,
      `it_ands_a_label_with_a_lane_filter`, `it_ands_two_labels`,
      `it_returns_the_whole_board_when_no_label_is_given`.
