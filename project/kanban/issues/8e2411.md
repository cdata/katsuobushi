## What to build

The `plan` skill: turn an accepted PDD into board cards. A new skill at
`plugins/katsuobushi/skills/plan/SKILL.md` (loads as `katsuobushi:plan`).

`/plan PDD007` reads the accepted PDD and splits it into **atomic** cards — one
card per unit of work, as the `project` skill defines it — and files each to
To-do. Each card carries (PDD002 Body):

- the PDD's **label** (e.g. `PDD007`), so the cards form an epic,
- a `blocked_by` edge to each card it depends on,
- a **type** from `feature|bug|chore|docs`,
- the PDD's matching **test cases** as `## Acceptance criteria`.

- **Files on its own; no approval wait.** The owner reorders/removes after.
- **To-do, not the icebox.** A plan is intended work, not a stray idea.
- Reference the `project` skill for the card model, types, and lifecycle — do not
  restate them. Use the `project new` verbs (`--label`, `--blocked-by`, `--body`).

Match the house voice/length of the existing skills.

## Acceptance criteria

- [ ] `plugins/katsuobushi/skills/plan/SKILL.md` exists with valid frontmatter,
      loading as `katsuobushi:plan`.
- [ ] `/plan PDD007` files every card to To-do carrying the `PDD007` label.
- [ ] A dependency between two cards is filed as a `blocked_by` edge.
- [ ] Each card's `## Acceptance criteria` holds the PDD's matching test cases.
- [ ] The skill files to To-do (not the icebox) and does not wait for approval.
- [ ] `markdown lint` clean; plugin/skill validators pass.
