## What to build

A `project labels` subcommand that enumerates the label vocabulary — the read
counterpart to the `--label` filter. A person runs it to see which epics/labels
exist and how big each is before filtering into one.

- **`project labels`** — one row per unique label: the label and the count of
  cards that carry it. Sorted by label.
- **`project labels --json`** — high-fidelity: for each label, the count and the
  list of card **ids** that carry it: `[{"label","count","ids":[...]}]`.
- **Archived cards are excluded by default.** A card in `## Archive`
  (accepted/cancelled) does not count. `--include-archived` adds them back in.
- **Iced notes count.** A label is a note property, so an iced note (no board
  card) contributes to its labels' counts — it is live, unfiled work.

### Seam

- New `labels` verb module beside `lint`/`query` in `project/`, wired through a
  `ProjectCommand::Labels { include_archived }` variant (main.rs) and a dispatch
  arm (mod.rs). `--json` is the existing global flag; emit through the renderer.
- Archived = `board.locate(&id) == Some(Location::Archive)`; active-lane cards
  and iced notes (`None`) are included. Labels come from `NoteMeta.labels`.
- Extract a pure `collect(board, notes, include_archived) -> Vec<LabelGroup>` so
  the aggregation is unit-tested directly (mirror `lint::evaluate`).

## Acceptance criteria

- [ ] `project labels` lists each unique label with a card count, sorted.
- [ ] `project labels --json` maps each label to its card ids + count.
- [ ] Archived cards are excluded by default; `--include-archived` includes them.
- [ ] Iced notes contribute to their labels' counts.
- [ ] Unit tests, BDD-named: `it_enumerates_unique_labels_with_counts`,
      `it_maps_each_label_to_its_card_ids`,
      `it_excludes_archived_cards_by_default`,
      `it_includes_archived_cards_with_the_flag`,
      `it_counts_iced_notes`.
