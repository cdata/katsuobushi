## What to build

`deliver.rs` builds its `--json` output with a hand-rolled format string
(`deliver.rs` line 87) that interpolates the user-supplied `branch` value
without escaping. `fetch.rs` only interpolates structurally safe values
(directory names and booleans), so `deliver` is the odd one out.

This is not reachable through a valid git ref — git rejects a double quote in a
ref name — so it is a correctness and consistency fix, not a live defect.

Found by the peer reviewer of card 69d1df; not blocking that card.

## Acceptance criteria

- [ ] `deliver`'s `--json` output cannot be malformed by its inputs
- [ ] The approach matches how the other sandbox verbs emit JSON
